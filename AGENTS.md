# Nova IPTV — agent notes

Expo SDK 57 / React Native 0.86 app targeting Android TV + Fire TV (APK), iOS and web from one codebase. Read README.md for features and build commands.

## Architecture rules

- **Focus is owned by JS, not the platform.** All D-pad/keyboard input flows through `src/input/keys.ts` (`useKeys(handler, enabled, layer)`). Higher layers win; within a layer the most recently mounted handler wins. Return `false` from a handler to let the event bubble (e.g. `left` at a screen's left edge opens the menu rail).
  - Android: `modules/remote-keys` wraps the React root view in `KeyCaptureLayout`, which forwards DPAD/media keys to JS so native focus never moves. Back goes through `BackHandler` → `dispatchKey({ key: 'back' })`.
  - Web: `src/input/remote.web.ts` listens in the capture phase and stops propagation, so DOM-focused buttons never double-handle Enter.
- Every pressable uses `focusable={false}`; focus visuals come from `focused` props (`Focusable`, `alwaysShowFocus` for the guide).
- **One video surface** (`src/player/VideoLayer.tsx`) positioned either over the guide's `PreviewSlot` (rect via `useVideoRect`) or fullscreen, so switching views never reloads the stream.
- Platform splits use file extensions: `*.web.ts(x)` for storage, HTTP picking, video surface, remote input.
- TV layout is designed on a 960×540 canvas and scaled with `useLayout().s()`; phones (portrait/narrow) get the compact layout.
- Styling comes from the Nova Night tokens in `src/theme.ts` (`colors`, `space`, `radius`, `typeScale`, `useLayout().type/k/safe`). Focus is always the white `focus` fill; web hover uses `hoverStyle` and must not imitate focus. Don't add hex literals in screens.
- No Expo Router: navigation is a small zustand store (`src/store/ui.ts`) because screens are driven by the key router.

## Commands

```bash
npx tsc --noEmit                 # typecheck (run before declaring work done)
npm run proxy && npm run web     # web dev (proxy on :8787, Metro on :8081)
npm run mock:xtream              # fake Xtream panel on :8790 (demo/demo)
```

`ios/` and `android/` are generated by `npx expo prebuild` — configure native behaviour through `app.json`, `plugins/`, and `modules/`, never by editing the generated folders.
